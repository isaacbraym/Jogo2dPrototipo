# Humor ácido brasileiro (VIVA!)

Spec completa: `docs/specs/SPEC-06-humor-e-tom.md` (limites inegociáveis na seção 2).

## Técnica (aplique 1 por texto, varie entre textos)
1. **Virada no fim**: fato normal → última frase inverte. "Você foi promovido(a). O salário não."
2. **Número concreto absurdo**: "áudio de 7 minutos", "14 figurinhas de bom dia", "R$ 1,50 com nota de 100".
3. **Eufemismo corporativo**: "Tradução: foi mandado(a) embora."
4. **Lista de três, a terceira absurda**: "Sem celular, sem videogame, sem direitos humanos."
5. **Anticlímax**: prepara algo grande e entrega algo mínimo.
6. **Resignação brasileira**: "Como manda a tradição." / "Bem-vindo(a) ao sistema."
7. **Fala do NPC que se entrega**: o entrevistador que confessa, o médico que cobra, a tia que pergunta.

## Revisão (antes de commitar, releia cada texto novo)
- [ ] O alvo da piada é a situação/sistema/o próprio jogador — não um grupo, não uma vítima vulnerável.
- [ ] Nada sexual com menores; nada de violência sexual/doméstica como piada; nada de suicídio como opção.
- [ ] Sem pessoas, partidos ou marcas reais.
- [ ] Cabe nos limites (título ≤ 32, texto ≤ 240, escolha ≤ 40, resultado ≤ 220, balão ≤ 45).
- [ ] Gênero neutro para o jogador `(a)`; NPC com `he(p, ...)`.
- [ ] Soa falado em voz alta por um comediante? Se precisa explicar, reescreva.
- [ ] A piada não se repete em estrutura com o texto anterior.
